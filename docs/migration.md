## 已知行为变化

- 雪橇云不再加载自己的 15 个业务集合，也不再使用 Microsoft/OpenAI 等服务选择组。机场业务规则不会与自有规则竞争顺序。
- GeekSpeed 原 27 条广告拒绝规则不纳入；本项目未新增广告拦截。
- 不明 checkout 例外及派生 DNS/Fake-IP/嗅探记录删除，交给后续规则和 GeoIP，不等于强制代理或拒绝。
- OpenAI 从动态 geosite 分类改为固定版本 v2fly 来源和官方语音 IP；Copilot 仅保留已审核专属条目，不继承旧机场整个共享父域和云厂商 ASN。
- 通用来源仍可能对共享服务作出分流，例如 Stripe 在通用代理中；不能声称所有共享服务都已经变成直连。
- 保留 ipstatp.com 的原雪橇云明确覆盖，避免替换来源后丢失；不整体搬入宽泛字节规则。
- 个人域名 DNS 按远程集合同步；IP/ASN/进程不机械变成 DNS 域名。保留节点解析策略和必要机场 Fake-IP/嗅探兼容项。

## 首次冲突基线

21 个来源的首批输入经复核登记 39 个同选择器跨策略冲突。后续新增冲突停止发布，不能自动放宽基线。

| 冲突类型 | 数量 | 采用的顺序 |
|---|---:|---|
| Google 与 Apple：crashlytics.com | 1 | Google 在前，代理 |
| TikTok 与国内：tiktokd.net / tiktokd.org | 2 | TikTok 在前，代理 |
| Apple/Microsoft 与通用代理 | 36 | 专项在前，直连 |

最后一类包括 Apple 的 apple-dns.net、appsto.re、digicert.com、itun.es、shazam.com；Microsoft 的 Azure/Bing/Live/OneDrive 等分类。保留专项先于通用顺序，完整选择器、来源与胜出策略见 `tests/source_baseline.json`。Copilot 入口、humb.apple.com、GitHub 下载保障等更早的窄规则继续优先。

冲突检查针对相同选择器；跨类型关键优先级用 expected_rule 回归检查，未声称能证明所有正则、进程和 IP 条件永不相交。未知 IP/地理信息保留 UNRESOLVED，不凭静态域名匹配宣称最终走代理。

## 验证范围

- 122 个策略/命中规则用例及 23 个官方语音网段，含 checkout 本域名/子域名在不同 IP 信息下的结果。
- 15 项脚本适配测试：主组、依赖、节点更新、幂等、DNS 顺序、无额外别名、原生保护下的异常及无法识别布局。
- 单元测试覆盖未知格式、计数异常、同数量换内容、策略冲突、下载失败、快照篡改、ZIP 确定性、发布权限及并发保护、保活 29/30 天边界。
- 两份真实候选 mihomo -t；另用纯合成 DIRECT 组启动隔离内核，确认全部 23 个集合逐条解析、下载失败保留旧缓存。

- 公开 CI 不读取本机真实配置。手机仓库和现用 Clash 文件不修改。连接效果及首次后台刷新待用户手动导入验收。
