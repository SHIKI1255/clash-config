# Clash Verge 安装、更新与回退

适用：Clash Verge Rev 2.5.8 / Mihomo 1.19.32。使用规则模式。
这是全局覆写包，不是机场节点订阅，也不是可替换机场的完整配置。

## 首次安装

1. 在本机备份现有全局扩展配置 Merge 和全局扩展脚本 Script；备份不要上传。
2. 下载 clash-overlay.zip，核对发布 SHA256SUMS。不要把 ZIP 当作 Verge 原生备份导入。
3. 在 Clash Verge 的设置中打开配置目录，将包中的 ruleset/personal-clash 复制到配置目录同名位置；这些是无凭据的首版缓存。
4. 订阅页编辑全局扩展配置（Merge），用 guard.yaml 的完整内容替换并保存。保护启用而新脚本未装好时，业务连接可能暂时停止。
5. 编辑全局扩展脚本（Script），用 override.js 的完整内容替换并保存。不要导入仓库 config/override.js 模板。
6. 当前两份订阅的专属 Merge/Script 和规则、分组覆写应保持空或无操作；检查后置覆写没有重新写入机场规则。
7. 手动重新激活原机场订阅。在机场主选择组选择节点；不需要单独创建 PROXY。
8. 检查所有 shiki_ 资源已加载，最终规则无机场 RULE-SET 引用。缺失缓存或首拉失败时先恢复上一配置，不视为安装成功。

GeekSpeed 主组为 GeekSpeed极客加速器；雪橇云主组为雪橇云。订阅名称必须与主选择组名称一致。
新增订阅无法匹配名称时进入保护状态，先确认真实主组并调整订阅显示名称，不猜测第一个组。
保留节点和必要 Hosts。所有代理服务、代理 DNS、资源下载跟随主组当前选择；主组主动选 DIRECT 也会直连。
主选择组不额外定时测速（interval: 0）；健康检查地址统一为 HTTPS Google 204、预期状态 204、超时 5 秒。
自动选择与故障转移组继续每 300 秒检查，自动选择容差为 100 毫秒。主组名称、节点顺序和选择能力保留。
官方语音 IP 集合继续参与业务分流和远程更新；它不含域名，因此不加入 nameserver-policy。
这些是本地覆写脚本设置，更新时必须手动同步新版 Script 或恢复新版完整备份，仅刷新远程规则不会生效。

## 更新边界

规则资源在内核运行时每 86400 秒更新，也可在客户端手动刷新。GitHub 每日构建与客户端刷新不是同步发生。
规则文件不含出口策略，出口和顺序由本地脚本定义。修改节点组适配、集合数量/顺序或 DNS 结构后需手动同步新版覆写。
各集合独立刷新，不能保证客户端原子切换全部文件；结构版本不兼容时先保留旧版，手动更新整个覆写包。
已有有效缓存时下载失败继续使用缓存；语法合法但语义错误由仓库发布检查防范，不能只依靠内核解析。
Mihomo 1.19.32 的隔离测试确认：首次无缓存且下载失败时，该集合可能为空，内核并不会自动进入 guard 的拒绝状态；后续规则仍可能继续匹配。因此首次安装必须放入附带快照并核对 23 个集合加载情况，不能仅看客户端显示“运行中”。部分集合因跨源去重合法为空，以发布清单计数为准。
机场节点订阅仍由 Verge 更新；GitHub 不读取私有订阅。

## 异常与回退

原生 guard.yaml 必须先于脚本启用。脚本异常时，规则模式下局域网保护继续，其余业务流量拒绝；不会恢复机场规则。
这是路由保护，不代表阻断所有后台 DNS/健康检查，也不适用于全局/直连模式。
升级前保留上一版两个覆写文件及缓存。恢复旧版本应同时恢复旧脚本、旧保护覆写和对应缓存。
完全退回安装前状态：先恢复旧全局脚本，再恢复旧全局配置；保留保护直到旧脚本已保存，然后手动重载。
固定版本下载：将 Raw URL 中 release 换成发布提交 SHA；包内资源 URL 默认仍跟踪 release。
需要冻结规则时，也将旧版 override.js 中 /release/rules/ 改为 /<发布SHA>/rules/，然后刷新资源。

## 验收

分别切换 GeekSpeed 和雪橇云，验证订阅更新后规则仍是自有规则，节点/Hosts 未丢失。
检查局域网、办公、远控、游戏、ChatGPT 登录/上传/语音及自动刷新。实际 UDP 可用性需实测。
PROCESS-NAME 的 DIRECT 只决定出口，不代表绕过 TUN。原 GeekSpeed 的 27 条广告拦截不再默认加载。

## 公共规则统一迁移

首次需手动同步本地覆写或恢复新版完整备份；只刷新规则不会将旧 provider 名称改为 shiki_。新版有 20 个有效 provider，保留 3 个旧补充 URL 兼容文件；旧覆写仍可下载。缓存路径不变。
三端公共修改在 https://github.com/SHIKI1255/shadowrocket-config/tree/main/shared；本地完整恢复包含凭据，仅在本机交付。禁止上传 GitHub。
